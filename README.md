# Out Of Mind — ADHD-Friendly Budget Tracker

A personal finance app designed around how ADHD brains actually work, focusing on tracking impluse purchases and mood. I have an interest in Product Management, and this here is my personal journey to see how much of this process clicks with me.  

## The Problem

Time blindness, impluse purchases, and an aversion to friction (unless its interesting!) can make it hard for some people with ADHD to consistently track their spending. My aim is to target this so that users can track their moods and become aware of possible spending patterns. 

## Status

🚧 Currently in active development — product design and wireframing complete, build in progress, guided by Claude.

## Planned Features

- Automated spending categorisation
- Visual, low-text spending summaries
- Impulse purchase cooling-off prompts
- Weekly digest instead of daily check-ins

## Tech Stack

- Python
- Flutter
- Balsamiq (wireframing and UX design)

## Design Process

Before writing a line of code, this project went through:

- User research (lived experience + community insights)
- Wireframing in Balsamiq
- UX review focused on cognitive load and ADHD-specific friction points
