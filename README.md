# Out Of Mind — ADHD-Friendly Budget Tracker

A personal finance app designed around how ADHD brains actually work.

## Status

In active development — product design and wireframing complete, and will upload soon.

## Features (Planned)
- Automated spending categorisation
- Visual, low-text spending summaries
- Impulse purchase cooling-off prompts
- Weekly digest instead of daily check-ins

- Flutter
- Balsamiq (wireframing)
